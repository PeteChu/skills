Verdict · request changes

The design is right: a fixed-window counter in Redis, mounted after auth, returning 429 with Retry-After. Two bugs make it unsafe to ship Thursday.

  • The counter is read and written in two round-trips, so bursts can blow past the limit.
  • Behind the ALB, every anonymous caller shares one bucket, so one scraper can lock out all signups.
