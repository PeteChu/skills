01

Color

Click a swatch to copy it. Contrast is computed against white so you know which ones can carry text.

Gotcha

signal-500 is only 3.0:1 on white, which passes for large text and fails for body copy. Use it for badges and fills. For orange text on light backgrounds, use signal-600 (4.6:1, AA). Six components in apps/ops currently set 13px text in signal-500.

02

Type scale

One family (--hb-font-sans, system UI stack) plus mono for container IDs and weights. Specimens use real tracker copy.

03

Spacing

A 4-based scale with a 2px hairline step. Bars are drawn at true size. Click a step to copy its variable.

04

Radius & elevation

Elevation is only used for things that float: menus, the map popover, toasts. Cards stay flat with a fog-200 border.
