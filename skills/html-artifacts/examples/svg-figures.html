#87867f · notes

  • Clay marks the one thing each figure is about: the tokens, the rolling window, the hot path, the bucket level.
  • Olive means allowed and rust means rejected in every figure, so readers learn the code once.
  • Strokes are 1.5px for neutral shapes and 2px for the emphasised box. Corners use rx="10" on boxes and rx="6" on chips.
  • Labels inside shapes are 11px mono. Annotations outside are 12px sans in gray-500.
  • Marker ids are prefixed per figure (f1-, f3-) so two pasted figures on one CMS page don't collide.
