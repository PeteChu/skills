04

What the sheet surfaced

None of these show up in Storybook, because each story renders one variant at a time. Fix them in the cva config so the new API cannot reproduce them.

  1. 1

    secondary has no pressed state

    Active is identical to hover, so the click gives no feedback. Add active:bg-[#E6EAEE] and a 1px inset shadow to match primary.

    Button.tsx:41 · variants.intent.secondary

  2. 2

    danger focus ring is brand green

    The ring comes from the shared focusRing constant, so the focused "Void invoice" button looks safe. Make the ring color a per-intent value.

    Button.tsx:28 · const focusRing

  3. 3

    ghost disabled fades to 30%, everything else to 45%

    At 30%, a disabled "Add line" button looks like placeholder text. Use one disabled:opacity-45 in the base class.

    Button.tsx:57 · ghost override

  4. 4

    sm + loading uses the 16px md spinner

    In a 28px button the spinner crowds the label and widens the button by 22px. Size the spinner from size (12 / 16 / 18).

    Spinner.tsx:9 · hard-coded w-4 h-4

  5. 5

    lg ghost keeps md padding

    The ghost class string includes px-3.5, which wins over the size's px-5 because the classes are joined without twMerge. Move padding out of the intent classes and into size only.

    Button.tsx:55 · cx(base, intent, size)

Proposed cva shape (fixes 1–5)

export const button = cva(base, {
  variants: {
    intent: {
      primary:   'bg-teal ring-teal',
      secondary: 'border active:bg-fog', // 1
      ghost:     'text-teal',  // 5: no px-*
      danger:    'bg-red ring-red',      // 2
    },
    size: {
      sm: 'h-7 px-2.5 [--spin:12px]',  // 4
      md: 'h-9 px-3.5 [--spin:16px]',
      lg: 'h-11 px-5 [--spin:18px]',
    },
  },
});
